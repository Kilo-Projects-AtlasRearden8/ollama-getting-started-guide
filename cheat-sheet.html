Ollama Cheat Sheet — print one page

Run AI models locally on your own computer. No account. No paid tier. Nothing leaves your machine.

Install Ollama

Mac / Linux:

curl -fsSL https://ollama.com/install.sh | sh

Windows: download the installer from ollama.com

Check it worked:

ollama --version

Your first model

ollama run llama3.2:3b

At the > > > prompt, type a message and press Enter.

Exit the chat: type /bye, or press Ctrl+D.

Download only: ollama pull llama3.2:3b

Manage models

CommandWhat it does
ollama listShow downloaded models
ollama pull <model>Download a model
ollama run <model>Download + start a chat
ollama rm <model>Delete a model
ollama --helpShow all commands

Free offline frontends

  • Ollama terminal: ollama run <model> — works offline after download
  • Enchanted: Mac/iPhone/iPad app connecting to local Ollama
  • Msty: Windows/Mac/Linux desktop app for local models
  • Open WebUI: web interface running on your computer (advanced)

Note: Frontends need internet once to install. After that, Ollama runs offline.

Troubleshooting

ProblemFix
ollama: command not foundRestart your terminal
Slow chatChoose a smaller model; close other apps
Out of memoryPick a smaller model (try llama3.2:1b)
Frontend cannot connectRun ollama serve in a terminal
