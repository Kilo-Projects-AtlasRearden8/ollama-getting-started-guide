Local AI with Ollama: A Beginner’s Manual

Asdale Dynamics, LLC — beginner-friendly AI education, plain English, step by step.

No account. No paid tier. Everything runs on your own computer.

1. What is Ollama?

Ollama is a free, open-source app that lets you run large language models (LLMs) — the kind of AI behind chatbots — directly on your own computer instead of on someone else’s server.

Why that matters:

  • Privacy. Your chats and files stay on your machine. Nothing is uploaded to Asdale Dynamics, LLC or any other company.
  • Offline. After you download a model once, you can chat with it with no internet connection.
  • Free. No sign-up, no credit card, no monthly subscription.
  • You choose the model. Small models for older laptops, bigger models for powerful desktops.

This manual walks you through installing Ollama, picking a model, running your first chat, and using free frontends that work offline. It assumes no programming experience.

2. What you need

ItemRequirement
ComputerMac, Linux, or PC (Windows 10/11)

AccountNone required

How much RAM does a model need?

As a rough guide, a model needs about 1 GB of RAM per billion parameters (written as "1B", "7B", "32B", etc.), plus a little extra for your system:

Model sizeRAM guidance
1B–3B modelsRun well on 8 GB RAM machines
7B–8B modelsThe sweet spot for beginners; 8–16 GB RAM
14B–32B modelsWant 16–32 GB RAM
70B+ modelsTypically need a strong graphics card and 48 GB+ RAM

You can always delete a model and try a smaller one if your computer feels slow.

3. Install Ollama

macOS

  1. Go to ollama.com and download Ollama for Mac, or open Terminal and run:
curl -fsSL https://ollama.com/install.sh | sh
  1. Drag Ollama into your Applications folder if you downloaded the app.
  2. Open Ollama. It places an icon in your menu bar.
  3. In Terminal, check that it works:
ollama --version

You should see something like ollama version is 0.6.x.

Linux

  1. Open a terminal and run the official install script:
curl -fsSL https://ollama.com/install.sh | sh
  1. The script installs Ollama and starts a background service.
  2. Check the version:
ollama --version

If the command is not found, log out and back in, or run source ~/.profile.

Windows

  1. Go to ollama.com and download Ollama for Windows.
  2. Run the installer and follow the prompts.
  3. Open PowerShell or Command Prompt and check:
ollama --version

4. Verify the installation

ollama --version

If you see a version number, Ollama is installed and ready.

5. Pick your first model

Models are the AI "brains" you chat with. Browse available models at ollama.com/library.

Good beginner models:

ModelSizeBest for
llama3.2:1b~1 GBVery old or slow computers
llama3.2:3b~2 GBFast, everyday chats on most laptops
llama3.1:8b~4.7 GBSmarter answers; needs 8–16 GB RAM
nomic-embed-text~274 MBTurning text into numbers (advanced)

To download and run a model in one step:

ollama run llama3.2:3b

Ollama downloads the model (this may take a few minutes) and opens a chat prompt that looks like:

> > >

Type your message and press Enter. Type /bye to exit, or press Ctrl+D.

6. Run your first chat

  1. Open your terminal (macOS/Linux) or PowerShell (Windows).
  2. Start a model:
ollama run llama3.2:3b
  1. At the > > > prompt, type something like:
Hello! Can you explain what AI is, like I'm new to this?
  1. Press Enter and read the reply.
  2. Try another:
Write a three-sentence bedtime story about a robot nurse.
  1. When you are done, type /bye or press Ctrl+D.

That’s it — you just ran AI locally on your own computer.

7. Manage your models

What you wantCommand

Run a modelollama run llama3.2:3b
Delete a modelollama rm llama3.2:3b

Example session:

ollama list
ollama pull llama3.1:8b
ollama run llama3.1:8b
# ... chat ...
# press Ctrl+D or type /bye
ollama rm llama3.2:3b

8. Free frontends that work offline

Ollama’s terminal chat is free and works offline, but many people prefer a visual app with a chat window. Here are free frontends you can run locally:

FrontendPlatformNotes
Ollama terminal (ollama run)Mac, Linux, WindowsSimplest offline option; works on every platform
EnchantedmacOS, iOSFree, open-source chat app connecting to local Ollama; works offline once installed
MstyWindows, macOS, LinuxFree desktop app with a polished chat interface; connects to Ollama on your machine
Open WebUIAny (via Docker)Feature-rich web interface for your local network; internet needed for initial setup, then runs locally

Important: Any frontend you download needs internet the first time to install. After that, Ollama plus your chosen model run entirely offline on your hardware.

9. Saving and sharing chats

Ollama does not sync chats to the cloud — that is the privacy benefit. If you want to keep a conversation:

  • Copy and paste the chat into a text file on your computer.
  • Use a frontend such as Enchanted or Open WebUI, which stores chat history locally.

10. Troubleshooting

ProblemFix
ollama: command not foundRestart your terminal, or log out and back in after installation
Download is slowInternet speed and model size determine download time; try a smaller model
Chat is very slowClose other apps; choose a smaller model (e.g. llama3.2:1b)
Out of memoryYour RAM is full; pick a smaller model or restart your computer
Frontend cannot connectMake sure Ollama is running (ollama serve in a terminal)
